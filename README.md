# 🌤️ SkyCast — Weather App

A Weather App built with Flutter that allows users to instantly check weather conditions by city name, view live updates, and enjoy a dynamic UI that changes colors based on the current weather condition.

---

## ✨ Key Features

- **City Search:** Search for any city worldwide with smooth navigation.
- **Live Weather Data:** Fetch live weather data using WeatherAPI and Dio.
- **Dynamic UI:** Beautiful dynamic gradients that change with the weather.
- **Accurate Weather Details:** Display temperature, minimum/maximum temperature, weather condition, and update time.
- **Weather Icons:** Display weather icons directly from the API.
- **Clean State Management:** Built with Flutter BLoC for predictable and organized state management.
- **Responsive Design:** Clean and maintainable code with a responsive user interface.

---

## 🏗️ Tech Stack

- **Framework:** Flutter (Dart)
- **State Management:** `flutter_bloc` (BLoC)
- **Networking:** `Dio`
- **Weather Data:** WeatherAPI
- **UI:** Dynamic gradients and API-based weather icons.

---

## 🚀 Getting Started

To run this project locally, make sure you have Flutter installed.

### 1. Clone the repository

```bash
git clone https://github.com/AmroKhaled20/Sky-Cast.git
```

### 2. Navigate to the project directory

```bash
cd Sky-Cast
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the app

```bash
flutter run
```
